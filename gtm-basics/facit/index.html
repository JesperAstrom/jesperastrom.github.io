Answer sheet

Every trigger, tag and variable from the lecture Google Tag Manager: triggers, tags and variables, with the exact settings. Names follow the pattern type - what. Field names are the ones Tag Manager shows.

What the container has at the end of the day 7 triggers, 5 tags, 12 user-defined variables, plus the six built-in Click variables switched on. The click versions of the hero and add-to-cart tags are deleted in step 31; they are listed here in case you want to compare.

Before everything

Built-In Variables

Variables → Built-In Variables → Configure → under Clicks, tick: Click Element, Click Classes, Click ID, Click Target, Click URL, Click Text.

The pushes the shop makes

All of them are in gtm-real-site/site/site.js. The full list is in the README of the shop course.

  • Every page, before the container loads: page.type, page.category, user.id, user.tier, user.consent.marketing. No event key.
  • cta_click: cta.text, cta.location (hero, hero_secondary, mid_page), cta.destination.
  • generate_lead: lead.plan, lead.bag_size, lead.source, lead.value, user.consent.marketing.
  • view_item_list, select_item, view_item, add_to_cart, begin_checkout, purchase: GA4 ecommerce object with ecommerce.items.0.*.
  • login, logout: user.*.
  • The footer newsletter form pushes nothing. That is the exercise 6 task in the shop course.
