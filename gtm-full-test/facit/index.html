Answer sheet: final test

The four pushes on Norrsken Outdoor, and one way to track each of them. Names follow the pattern type - what. Any setup that gets all parameters into DebugView is a pass.

A full pass 4 Custom Event triggers, 9 Data Layer Variables, 4 GA4 Event tags, and every parameter visible in DebugView with the right value. The quantity in add_to_cart must follow the number typed on the page.

1. The link

{ event: 'link_click', link: { text: 'Read our story', url: '#story', location: 'card' } }
Trigger: CE - link_clickCustom Event, event name link_click
Variablesdlv - link.text → link.text
dlv - link.url → link.url
Tag: GA4 - link_clickGA4 Event, name link_click, parameters link_text = {{dlv - link.text}}, link_url = {{dlv - link.url}}

Also acceptable: a Click - Just Links trigger filtered on Click ID equals story-link, with the built-in Click Text and Click URL variables. The dataLayer version is the one the course taught.

2. The button

{ event: 'button_click', button: { id: 'discount-button', text: 'Get a discount code', coupon: 'NORRSKEN10' } }
Trigger: CE - button_clickCustom Event, event name button_click
Variablesdlv - button.text → button.text
dlv - button.coupon → button.coupon
Tag: GA4 - button_clickGA4 Event, name button_click, parameters button_text = {{dlv - button.text}}, coupon = {{dlv - button.coupon}}

3. The form

{ event: 'form_submit', form: { name: 'newsletter', interest: 'hiking', method: 'email' } }
Trigger: CE - form_submitCustom Event, event name form_submit
Variablesdlv - form.name → form.name
dlv - form.interest → form.interest
Tag: GA4 - generate_leadGA4 Event, name generate_lead, parameters form_name = {{dlv - form.name}}, interest = {{dlv - form.interest}}

The interest parameter must change when a different option is chosen before submitting. That is the check that the variable reads the dataLayer and is not typed in by hand.

4. The product

{ ecommerce: null }
{ event: 'add_to_cart', ecommerce: { currency: 'SEK', value: 2590,
    items: [{ item_id: 'NO-HL-800', item_name: 'Polar 800', item_category: 'Headlamps',
              item_brand: 'Norrsken', price: 1295, quantity: 2 }] } }
Trigger: CE - add_to_cartCustom Event, event name add_to_cart
Variablesdlv - ecommerce.items → ecommerce.items
dlv - ecommerce.value → ecommerce.value
dlv - ecommerce.currency → ecommerce.currency
Tag: GA4 - add_to_cartGA4 Event, name add_to_cart, parameters items = {{dlv - ecommerce.items}}, value = {{dlv - ecommerce.value}}, currency = {{dlv - ecommerce.currency}}

Simpler and also correct: in the tag, tick Send Ecommerce data with data source Data Layer, and skip the three variables. The check is that DebugView shows quantity 2 after typing 2 on the page, and value 2590.

Common mistakes

  • Trigger type Click instead of Custom Event: fires, but the parameters are empty.
  • Variable path link_text instead of link.text: undefined.
  • Trigger event name typed with a capital letter or a space: never fires.
  • Snippet pasted only in head: the container still works, the noscript part is only for browsers without JavaScript.
  • Tag Assistant cannot connect: the page is opened from disk. It must be online, on the student's github.io address.
