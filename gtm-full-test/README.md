# Tag Manager final test

`index.html` is one page with no tracking code: a link, a button, a form and a product. Each pushes an event to the dataLayer when used.

The student copies the page to their own site, pastes their own Tag Manager snippet on the two marked lines, and builds the triggers, variables and GA4 event tags for all four events.

`facit/index.html` is the answer sheet for the teacher.
