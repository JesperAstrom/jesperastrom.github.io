Steg 5–6

Summera, sedan titta inåt

Först en ihopslagen text per kluster som hela klassen kan läsa. Sedan tre lappar som bara är dina.

Steg 5

Det här kan vi om …

Röd + Blå ihopslagna med "Ja, och". Ett stycke per läromål. Avsluta med "Det här behöver klassen förstärka: …"

Kluster A

Datadrivet arbetssätt

Det här kan vi om …

Kluster B

Mäta och samla in

Det här kan vi om …

Kluster C

Analysera och bearbeta

Det här kan vi om …

Kluster D

Hitta tillväxt och rekommendera

Det här kan vi om …

Steg 6

Min egen reflektion

Tre lappar per person. Skriv ditt namn på dem om du vill, annars inte.

1

Vad är jag stolt över?

Vad i texterna kan jag redan? Vilka lappar var mina? Minst tre saker.

2

Vad kan andra som jag inte kan?

Vad hade jag inte kunnat skriva själv? Vem satte den lappen?

3

Vad förstärker jag, och hur?

En eller två saker. Vad gör jag nästa vecka, och vem frågar jag?
