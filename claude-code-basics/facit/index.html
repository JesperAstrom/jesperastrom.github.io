Answer sheet

Every command from the lecture Claude Code in VS Code: install it and organise your projects, what each one should print, the folder tree you end up with, and what to do when a step fails. Commands are the same on macOS and Windows unless the sheet says otherwise.

What your computer has at the end of the day VS Code with the Claude Code extension, Claude Code installed and logged in, a folder ~/AI-projects in your home folder, and two projects inside it: hello-page (with index.html and CLAUDE.md) and recipe-list (with recipes.md).

The finished folder tree

Home folder              macOS: /Users/yourname   Windows: C:\Users\yourname
├── AI-projects          the parent folder (step 8)
│   ├── hello-page       project 1 (step 9)
│   │   ├── index.html   step 12
│   │   └── CLAUDE.md    step 13
│   └── recipe-list      project 2 (step 14)
│       └── recipes.md   step 16
└── .claude              hidden. Login, settings, saved conversations. Made by Claude Code, not by you.

Part 1 · Install

Step 2 · Open the terminal in VS Code

MenuTerminal → New Terminal
ShortcutCtrl + `  (the key under Escape, on both macOS and Windows)
Checkpwd  →  /Users/yourname  or  C:\Users\yourname

Step 3 · Install Claude Code

macOS (zsh)curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell)irm https://claude.ai/install.ps1 | iex
Windows (Git Bash)curl -fsSL https://claude.ai/install.sh | bash
If curl is blockedbrew install --cask claude-code  (macOS)
winget install Anthropic.ClaudeCode  (Windows)

Source: code.claude.com/docs/en/setup. The installer updates itself in the background afterwards. Nothing else needs to be installed first.

Step 4 · Check the install

Commandclaude --version
Expected2.1.278 (Claude Code)  your number will be higher
If "command not found"Quit VS Code completely (macOS: Cmd+Q) and open it again. Then run claude doctor; it tells you what is wrong.

Step 5 · The VS Code extension

WhereExtensions view (Cmd+Shift+X on macOS, Ctrl+Shift+X on Windows)
Search forClaude Code
PublisherAnthropic  (id: anthropic.claude-code)
NeedsVS Code 1.94 or newer
CheckA Claude icon at the top right of the VS Code window.

Running claude in the terminal does not install the extension. It must come from the Marketplace. If you started Claude Code in a terminal before installing the extension, type /ide inside Claude Code to connect it to the open VS Code window.

Part 2 · One folder per project

Steps 8 and 9 · Create the folders

# the parent folder
mkdir ~/AI-projects

# the first project
mkdir ~/AI-projects/hello-page

# check
ls ~/AI-projects
# → hello-page

mkdir makes a folder, ls lists a folder, ~ is your home folder. All three work in zsh on macOS and in PowerShell on Windows. Folder names: lowercase letters, numbers and dashes. No spaces.

Step 10 · Open the project folder in VS Code

MenuFile → Open Folder…  (macOS: File → Open…)
PickHome folder → AI-projects → hello-page → Open
Trust dialogYes, I trust the authors
CheckExplorer heading says HELLO-PAGE. A new terminal (Terminal → New Terminal) answers pwd with a path ending in /AI-projects/hello-page.

Steps 11 and 12 · Start Claude Code and build

claude
# welcome box shows: cwd: /Users/yourname/AI-projects/hello-page

> Which folder are you working in?
> Create a file called index.html with a simple web page that says "Hello from hello-page".
# answer Yes to the permission question
Checkindex.html appears in the Explorer. Right-click → Reveal in Finder / File Explorer, double-click it, the browser shows "Hello from hello-page".
Permission answersYes = this change only. Yes, and don't ask again = this kind of change for the rest of the conversation. No = skip it and tell Claude what to do instead.

Step 13 · CLAUDE.md

Command/init
ResultA file CLAUDE.md in the project folder. Claude Code reads it every time it starts in this folder.
Edit itOpen it from the Explorer, or type /memory inside Claude Code.
Write in itWhat the project is, who it is for, and rules you do not want to repeat. Plain sentences.

A good first CLAUDE.md for hello-page:

# hello-page

A single static web page used to learn Claude Code.
Keep everything in one file, index.html. No frameworks, no build step.
Write all visible text in Swedish.

Part 3 · Switching between projects

Steps 14 to 16 · Second project

/exit
mkdir ~/AI-projects/recipe-list
ls ~/AI-projects
# → hello-page   recipe-list
New windowFile → New Window, then File → Open Folder… → AI-projects → recipe-list
TerminalTerminal → New Terminal in the new window. pwd ends with recipe-list.
Startclaude
Ask"Is there a file called index.html here?" → No. Claude Code only sees recipe-list.
Build"Create recipes.md with a list of three breakfast recipes." → recipes.md appears in recipe-list only.
Switch windowsWindow menu, or Cmd+` on macOS, Alt+Tab on Windows

Steps 17 and 18 · Come back to a conversation

claudeStarts a new conversation in the folder you are standing in.
claude --continueReopens the latest conversation in this folder.
claude --resumeShows a list of all conversations in this folder. Arrow keys and Enter to pick one.
claude --resume NAMEOpens the conversation you named.
/rename NAMEInside Claude Code: gives the current conversation a name.

Conversations are saved per folder, in ~/.claude/projects/. A conversation from recipe-list never shows up in hello-page. Saved conversations are kept for 30 days by default.

Step 19 · Where things live

~/AI-projects/All your projects. Back this folder up.
~/AI-projects/NAME/CLAUDE.mdInstructions for that one project.
~/AI-projects/NAME/.claude/settings.jsonSettings for that one project, for example what Claude Code may do without asking.
~/.claude/CLAUDE.mdInstructions for every project you have.
~/.claude/settings.jsonYour settings for every project.
~/.claude/projects/Saved conversations, one subfolder per project folder. Do not edit by hand.

Step 20 · The four rules

  • New idea, new folder. mkdir ~/AI-projects/new-idea
  • Open the project folder in VS Code. Not the parent folder, not the home folder.
  • Start Claude Code from a terminal in that window. Read the cwd line in the welcome box.
  • Write a CLAUDE.md early. One paragraph is enough.
Never start claude in your home folder, on the Desktop or directly in AI-projects. It would read everything in there and treat it as one project. If one project needs to read another, type /add-dir ~/AI-projects/other-project inside Claude Code instead.

When something fails

command not found: claudeOld terminal. Quit VS Code fully and reopen. Then claude doctor.
Login loops or says free planClaude Code needs Pro, Max, Team or an API account. Check at claude.ai. Then /logout, /login.
Claude says the folder is empty but it is notIt is standing in the wrong folder. Type /exit, check pwd, open the right folder with File → Open Folder, open a new terminal, start again.
Files land in the wrong folderSame cause. The cwd line in the welcome box tells you where files will go.
pwd still shows the home folder after Open FolderThe terminal panel is older than the folder. Close it (bin icon) and open a new one.
Windows: install command errors in the terminalCheck the prompt. PS = PowerShell, use the irm command. bash = Git Bash, use the curl command.
Claude Code is out of dateclaude update in the terminal.
