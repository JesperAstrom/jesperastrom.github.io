Claude Code in VS Code

$ claude

Growth ToolboxInstall it and organise your projectsJesper Åström

Two lines of terminal frame the title on purpose. The whole lecture is those two lines: go to a folder, start Claude Code there. Today: install it, put it inside VS Code, build a folder structure, and switch between projects without mixing them up.

Intro

What is Claude Code?

An AI assistant that runs in a terminal and works on the files in one folder.

The chat on claude.ai

  • You paste text in. You copy text out.
  • It cannot see your files.
  • It cannot create or change files on your computer.

Claude Code

  • You start it inside a folder on your computer.
  • It reads the files in that folder, creates new ones and edits them, after asking you.
  • Inside VS Code you see every change as a diff before you accept it.
Ask: who has copied code from a chat window into a file and got it wrong? Claude Code removes the copying. It works directly in the folder. The price is that you have to be careful about which folder you start it in. That is the whole of Part 2 and 3.

Intro

The one idea to remember

A folder is a project. Claude Code sees the folder you start it in, and nothing else.

  1. You open a folder in VS Code.
  2. You open a terminal in VS Code. The terminal starts in that folder.
  3. You type claude. Claude Code starts in that folder.
  4. Everything it reads and writes stays inside that folder. Your conversation is saved for that folder too.
# the folder you start in = the project
$ cd ~/AI-projects/hello-page
$ claude

╭──────────────────────────────╮
│ Welcome to Claude Code        │
│ cwd: ~/AI-projects/hello-page │
╰──────────────────────────────╯
cwd means current working directory. Say it in plain words: the folder you are standing in. If students start Claude Code on the Desktop, it will treat the whole Desktop as one project. That is the mistake we prevent with the parent folder.

Intro

Our folder structure

One parent folder for all AI projects. One subfolder per project. Nothing else inside.

Home folder  (Users/yourname)
└── AI-projects       ← the parent folder
    ├── hello-page    ← project 1
    │   ├── index.html
    │   └── CLAUDE.md
    ├── recipe-list   ← project 2
    │   └── CLAUDE.md
    └── …             ← every new idea
  • You always know where things are. Every project is one folder in one place.
  • Projects cannot mix. Claude Code in recipe-list never touches hello-page.
  • Easy to back up, share or delete. Zip one folder, or drag it to the bin.
  • Easy to open. In VS Code you open the project folder, not the parent.
We build exactly this tree today. Name of the parent folder is a suggestion; the rule is that it exists, that it is in the home folder, and that every project is a direct subfolder of it. Lowercase names with dashes, no spaces: spaces cause trouble in terminals.

Intro

What you need before we start

Three things. Check them now. The slides show macOS first and add the Windows command where it differs.

A computer you can install on

macOS or Windows 10/11. You need to be allowed to install programs.

A Claude account

Claude Code needs a paid plan: Claude Pro or Max at claude.ai, or an API account at console.anthropic.com.

Internet

The installer downloads Claude Code. Logging in opens a browser window.

Done when you can log in at claude.ai and see a Pro or Max plan, or you have an API account with credits.
Do this check before the install slides, not after. Students on the free plan get stuck at the login step. If the school pays for a Team plan, that works too.

Part 1 of 3

Install

VS Code, then Claude Code, then the extension that joins them. Log in once.

Part 1Step 1 of 20

Install VS Code

  1. Go to code.visualstudio.com.
  2. Click the big blue Download button. It picks the right version for your computer.
  3. macOS: open the downloaded zip, drag Visual Studio Code into the Applications folder.
    Windows: run the downloaded installer and click Next until it finishes.
  4. Open VS Code.

Already have VS Code?

Open it and choose Help → About (on macOS: Code → About Visual Studio Code).

The version must be 1.94 or newer for the Claude Code extension. If it is older, choose Help → Check for Updates.

Done when VS Code is open and shows its Welcome page.
Most students have VS Code already. Use the time to check versions. On macOS the first launch asks whether to open a downloaded app: click Open.

Part 1Step 2 of 20

Open the terminal inside VS Code

  1. In the top menu, choose Terminal → New Terminal.
  2. A panel opens at the bottom of the window. This is the terminal.
  3. The last line ends with a prompt. On macOS it looks like yourname@MacBook ~ %. On Windows it looks like PS C:\Users\yourname>.

Keyboard shortcut: Ctrl + ` (the key under Escape) on both macOS and Windows.

# macOS: the terminal is zsh
yourname@MacBook ~ % █

# Windows: the terminal is PowerShell
PS C:\Users\yourname> █

The ~ and C:\Users\yourname both mean your home folder. That is where the terminal starts when no folder is open.

Done when you see the prompt and a blinking cursor. Type pwd and press Enter: it prints your home folder.
pwd = print working directory. It works in both zsh and PowerShell. Get every student to run it now; the answer tells them where they are, which is the skill this lecture is about.

Part 1Step 3 of 20

Install Claude Code

  1. Click in the terminal panel.
  2. Copy the command for your computer from the right and paste it into the terminal.
  3. Press Enter. Text scrolls by for a minute. Wait for the prompt to come back.

This is the installer from Anthropic's own instructions at code.claude.com/docs. It keeps itself updated afterwards.

# macOS
% curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
PS> irm https://claude.ai/install.ps1 | iex
Windows only If the terminal says bash instead of PS, you are in Git Bash. Use the macOS command there instead.
Done when the last lines say that Claude Code was installed and the prompt is back.
The macOS installer may ask for the computer password. Windows may show a SmartScreen or execution policy question; answer Yes / Run. If the school blocks curl, the fallback is Homebrew (brew install --cask claude-code) or winget install Anthropic.ClaudeCode.

Part 1Step 4 of 20

Check that it works

  1. Close the terminal panel: click the bin icon at its top right. Then open a new one with Terminal → New Terminal. A fresh terminal knows about the new program.
  2. Type claude --version and press Enter.
  3. Read the answer. It is a version number followed by (Claude Code).
% claude --version
2.1.278 (Claude Code)

# if instead you see this:
zsh: command not found: claude
# → quit VS Code completely and open it again
Done when claude --version prints a version number. Your number will be newer than the one on the slide.
"command not found" is almost always an old terminal. Quit VS Code fully (Cmd+Q on Mac), reopen, try again. If it still fails, run: claude doctor. It prints where the install went wrong.

Part 1Step 5 of 20

Install the VS Code extension

  1. Click the Extensions icon in the left bar of VS Code (four small squares), or press Cmd+Shift+X on macOS, Ctrl+Shift+X on Windows.
  2. In the search box, type Claude Code.
  3. Pick the one whose publisher is Anthropic. Click Install.

What the extension adds

  • A Claude button at the top right of VS Code that opens Claude Code in a side panel.
  • Every file change shows as a diff in the editor before you accept it.
  • Select some lines in a file and Claude Code sees your selection.
Done when the extension page shows Uninstall instead of Install, and a Claude icon appears at the top right of the VS Code window.
The extension id is anthropic.claude-code. Running claude in the terminal does not install it; it must come from the Marketplace. We still use the terminal in this lecture because the terminal shows the folder. The panel does the same thing; students may use either.

Part 1Step 6 of 20

Log in

  1. In the terminal, type claude and press Enter.
  2. The first time, it asks a few questions. Use the arrow keys and Enter to answer. Pick any colour theme.
  3. When it asks how to log in, choose Claude account with subscription if you have Pro or Max. Choose the Console option if you have an API account.
  4. A browser window opens. Log in and click Authorize. Go back to VS Code.
% claude

Select login method:
❯ 1. Claude account with subscription
  2. Anthropic Console account

# after the browser step:
Login successful. Press Enter to continue…
Done when you are back in the terminal and see the Claude Code welcome box with a text field at the bottom. Type /status and press Enter: it shows your account email.
If the browser did not open, the terminal prints a link; press c to copy it and paste it in a browser. Wrong account? Type /logout, then /login. The login is saved on the computer; they do this once.

Part 1Step 7 of 20

Say hello, then leave

  1. In the text field at the bottom, type: Which folder are you working in? Press Enter.
  2. Read the answer. It names your home folder, because that is where the terminal started.
  3. Type /exit and press Enter. You are back at the normal prompt.

Anything starting with / is a command to Claude Code itself. /help lists them all. Anything else is a message to Claude.

> Which folder are you working in?

I'm working in /Users/yourname, which is
your home folder.

> /exit
Goodbye!
yourname@MacBook ~ % █
Do not build anything here. Your home folder holds everything on the computer. Claude Code would treat all of it as one project. Part 2 gives it a proper home.
This is the deliberate wrong example. Let them see Claude Code answer "home folder", then exit. Next part fixes it. Ctrl+D twice also exits.

Part 2 of 3

One folder per project

Create the parent folder, create your first project inside it, and start Claude Code there.

Part 2Step 8 of 20

Create the parent folder

  1. In the terminal, type the command on the right and press Enter. It creates a folder called AI-projects in your home folder.
  2. Nothing is printed. That means it worked.
  3. Check: open Finder (macOS) or File Explorer (Windows) and look in your home folder. The new folder is there.

You can also create it with right-click → New Folder in Finder or Explorer. The terminal way is the same on every computer, so the slides use it.

# macOS and Windows, same command
% mkdir ~/AI-projects

# check where it went
% ls ~
AI-projects  Desktop  Documents  Downloads …

mkdir = make directory. ~ = your home folder. ls = list what is in a folder.

Done when ls ~ lists AI-projects next to Desktop and Documents.
On Windows PowerShell, mkdir and ls both work, and ~ means the home folder. Finder on macOS hides the home folder by default: press Cmd+Shift+H to open it. Do not let students put the parent folder on the Desktop or in iCloud Drive; syncing folders while Claude Code writes files causes odd errors.

Part 2Step 9 of 20

Create your first project folder

  1. In the terminal, type the command on the right and press Enter. It creates a folder called hello-page inside AI-projects.
  2. Type ls ~/AI-projects and press Enter. It lists hello-page.

Naming rule

Lowercase letters, numbers and dashes only. hello-page, not Hello Page. Spaces and capital letters cause trouble in terminals later.

% mkdir ~/AI-projects/hello-page
% ls ~/AI-projects
hello-page
AI-projects
└── hello-page   ← empty, for now
Done when ls ~/AI-projects prints hello-page.
Every future project is this one command with a new name. Say that out loud: "new idea, new mkdir inside AI-projects".

Part 2Step 10 of 20

Open the project folder in VS Code

  1. In the top menu choose File → Open Folder… (on macOS the item is called File → Open…).
  2. Go to your home folder, open AI-projects, select hello-page and click Open.
  3. VS Code asks Do you trust the authors of the files in this folder? Click Yes, I trust the authors. It is your own folder.

What changed

  • The Explorer on the left now says HELLO-PAGE at the top. It is empty.
  • The window title says hello-page.
  • Every new terminal you open from now on starts inside hello-page.
Done when the Explorer heading reads HELLO-PAGE. Open a new terminal (Terminal → New Terminal), type pwd: it ends with /AI-projects/hello-page.
This is the key slide. VS Code window = one folder = one project. The terminal follows the window. Claude Code follows the terminal. If a student's pwd still says the home folder, they opened a file instead of the folder, or they are using an old terminal panel; close it and open a new one.

Part 2Step 11 of 20

Start Claude Code in the project

  1. In the terminal, which is now inside hello-page, type claude and press Enter.
  2. Read the welcome box. The line cwd shows the folder Claude Code is working in.
  3. Ask again: Which folder are you working in? This time the answer ends with hello-page.
% claude

╭─ Welcome to Claude Code
│  cwd: ~/AI-projects/hello-page
╰─

> Which folder are you working in?
/Users/yourname/AI-projects/hello-page.
It is currently empty.
Done when the cwd line and Claude's answer both end with hello-page.
Compare with step 7. Same command, different folder, different project. Claude may also ask "Do you trust the files in this folder?" the first time; answer Yes.

Part 2Step 12 of 20

Let Claude Code build something

  1. Type this message and press Enter:
    Create a file called index.html with a simple web page that says "Hello from hello-page".
  2. Claude Code shows what it wants to write and asks for permission. Press Enter on Yes.
  3. Look at the Explorer on the left. index.html has appeared.
  4. Right-click index.html in the Explorer → Reveal in Finder (Windows: Reveal in File Explorer) and double-click it. It opens in your browser.
AI-projects
└── hello-page
    └── index.html   ← new

Why it asked first

Yes allows this one change. Yes, and don't ask again allows the same kind of change for the rest of the conversation.

Done when the browser shows the text Hello from hello-page and the file sits inside the hello-page folder.
This is the payoff: no copy-paste. The file exists on disk, in the right folder, and the browser shows it. With the extension installed, VS Code also opens the file as a diff; students accept it there or in the terminal, both work.

Part 2Step 13 of 20

Give the project a memory: CLAUDE.md

  1. Type /init and press Enter. Claude Code reads the folder and writes a file called CLAUDE.md. Allow it.
  2. Open CLAUDE.md from the Explorer. It is a plain text note about the project.
  3. Add one line at the end, in your own words, for example: Always write the page text in Swedish. Save with Cmd+S / Ctrl+S.

What CLAUDE.md is

  • A note that Claude Code reads every time it starts in this folder.
  • Write what the project is, and rules you are tired of repeating.
  • It belongs to this project only. The next project gets its own.
Done when CLAUDE.md is in the hello-page folder next to index.html, with your line at the end.
CLAUDE.md is the project's instruction sheet. /memory opens it from inside Claude Code. There is also ~/.claude/CLAUDE.md for rules that apply to every project; mention it, do not make them edit it today.

Part 3 of 3

Switching between projects

A second project, a second window, and how to come back to a conversation.

Part 3Step 14 of 20

Create a second project

  1. In the terminal, type /exit and press Enter to leave Claude Code.
  2. Type the command on the right and press Enter. It creates recipe-list next to hello-page.
  3. Type ls ~/AI-projects. It now lists both.

The command uses the full path from ~, so it works no matter which folder the terminal is standing in.

> /exit
% mkdir ~/AI-projects/recipe-list
% ls ~/AI-projects
hello-page   recipe-list
AI-projects
├── hello-page
│   ├── CLAUDE.md
│   └── index.html
└── recipe-list   ← new, empty
Done when ls ~/AI-projects prints both hello-page and recipe-list.
Same move as step 9. Point at the tree: two siblings under one parent. Nothing inside hello-page changed.

Part 3Step 15 of 20

Open it in a new VS Code window

  1. Choose File → New Window. An empty VS Code window opens. Your hello-page window stays open behind it.
  2. In the new window choose File → Open Folder… (macOS: File → Open…), go to AI-projects, select recipe-list, click Open. Trust the folder.
  3. Open a terminal in this window: Terminal → New Terminal. Type pwd. It ends with recipe-list.

One window per project

  • Each VS Code window is one folder.
  • Each window has its own terminal, standing in its own folder.
  • Switch projects by switching windows: Window menu, or Cmd+` on macOS.
Done when you have two VS Code windows, titled hello-page and recipe-list, and pwd in the new window ends with recipe-list.
Alternative if two windows confuse someone: File → Open Folder in the same window replaces the project. That also works; the terminal restarts in the new folder. Two windows is better for showing that projects are separate.

Part 3Step 16 of 20

Prove the projects are separate

  1. In the recipe-list window's terminal, type claude and press Enter.
  2. Ask: Is there a file called index.html here?
  3. Read the answer: no. Claude Code in recipe-list cannot see hello-page. It does not know it exists.
  4. Ask it to build something for this project: Create recipes.md with a list of three breakfast recipes. Allow it.
cwd: /Users/yourname/AI-projects/recipe-list

> Is there a file called index.html here?
No. This folder is empty.

> Create recipes.md with a list of three
  breakfast recipes.
Created recipes.md
Done when recipes.md is in recipe-list, and hello-page still has only index.html and CLAUDE.md.
Check the hello-page window's Explorer together: unchanged. This is what the folder structure buys you. Also run /init here so recipe-list gets its own CLAUDE.md, if there is time.

Part 3Step 17 of 20

Continue where you left off

  1. Switch to the hello-page window.
  2. In its terminal, type claude --continue and press Enter.
  3. Your earlier conversation comes back on screen. Ask: What did we build here? It remembers the hello page.

Conversations are saved per folder. claude --continue reopens the latest one for the folder you are standing in. It will never bring up a recipe-list conversation inside hello-page.

# in the hello-page window
% claude --continue

… Which folder are you working in?
… Create a file called index.html …
… /init

> What did we build here?
A one-page site, index.html, that says
"Hello from hello-page", plus a CLAUDE.md.
Done when Claude Code describes index.html without you telling it anything.
Plain claude starts a fresh conversation, which is fine most days. --continue is for "I was in the middle of something". Both are typed at the normal prompt, not inside Claude Code.

Part 3Step 18 of 20

Pick an older conversation

  1. Type /exit. Then type claude --resume and press Enter.
  2. A list of every conversation in this folder appears, newest first. Use the arrow keys and Enter to open one.
  3. To make a conversation easy to find later, name it: inside Claude Code type /rename hello-page-setup.
Type at the promptWhat happens
claudeNew conversation in this folder.
claude --continueReopens the latest conversation in this folder.
claude --resumeLets you pick any conversation in this folder.
claude --resume hello-page-setupOpens the conversation with that name.
Done when you have opened the list, picked a conversation, and given it a name.
Conversations are kept for 30 days by default. Names are optional; the picker shows the first message of each conversation, which is usually enough.

Part 3Step 19 of 20

Know where everything lives

PlaceWhat is thereWho it belongs to
~/AI-projects/All your projects, one folder each.You. Back this up.
~/AI-projects/hello-page/CLAUDE.mdInstructions Claude Code reads when it starts in that project.That project.
~/AI-projects/hello-page/.claude/Settings for that project, for example what Claude Code may do without asking.That project.
~/.claude/Your login, your settings for all projects, and every saved conversation, sorted by project folder.You. Do not edit by hand.
~/.claude/CLAUDE.mdInstructions for every project, for example "answer in Swedish".You.
Done when you can answer: where do I put a new project, and where do I write a rule that applies to that project only?
Folders starting with a dot are hidden in Finder and Explorer. Cmd+Shift+. shows them on macOS. Students do not need to open ~/.claude today; they need to know it exists so they do not delete it.

Part 3Step 20 of 20

Four rules for every new project

  1. New idea, new folder. mkdir ~/AI-projects/new-idea. Lowercase, dashes.
  2. Open the project folder in VS Code, never the parent and never the home folder.
  3. Start Claude Code from a terminal in that window. Check the cwd line.
  4. Write a CLAUDE.md early. One paragraph: what this is, what it is for, what to avoid.
Never start claude in your home folder, on the Desktop or in AI-projects itself. It would read everything in there and treat it as one project.

Need two folders at once?

Inside Claude Code, type /add-dir ~/AI-projects/recipe-list. It can then read that folder too, for this conversation only.

Done when you have written the four rules at the top of your own ~/.claude/CLAUDE.md, or on a sticky note.
Close the loop: the mistake from step 7 is now impossible if they follow rule 2 and 3. /add-dir is the escape hatch for the rare case where one project needs to read another.
